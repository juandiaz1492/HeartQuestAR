
# HeartQuest AR

An augmented reality application designed to help healthcare students learn human heart anatomy through interactive 3D exploration and quizzes.

## Project Documentation

[HeartQuest AR - Project Definition](https://docs.google.com/document/d/1toJYPvPvYA_CUmagfrvKMdOD5AHEVwTVCjpTfPQf4Zg/edit?usp=sharing)

## Main Features

- Study Mode: Explore the 3D heart and learn the names and functions of its anatomical structures.
- Quiz Mode: Identify specific structures directly on the interactive 3D model.
- Augmented Reality: Place the heart in the real environment using a smartphone.
